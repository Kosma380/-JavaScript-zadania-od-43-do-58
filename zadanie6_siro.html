Zadanie 6 – Teoria

1) Rodzaje okienek
Okienko alert – wyświetla komunikat z informacją i przyciskiem OK.
Okienko prompt – pozwala użytkownikowi wpisać wartość, którą program może później wykorzystać.
Okienko confirm – umożliwia potwierdzenie lub odrzucenie akcji przez użytkownika (OK lub Cancel).

2) Konwersji liczb
Podczas wczytywania danych przez prompt wartości są zapisywane jako ciąg znaków (string). Aby można było wykonać obliczenia, należy wykonać konwersję do typu liczbowego:
parseFloat(zmienna) – konwersja na typ zmiennoprzecinkowy.
parseInt(zmienna) – konwersja na liczbę całkowitą.
toString(zmienna) – konwersja do typu tekstowego (łańcuch znaków).

3) Przy nadawaniu nazw zmiennym należy przestrzegać pewnych zasad:
1️⃣ Nazwa musi zaczynać się od litery, „$” lub „_” i może zawierać tylko litery, cyfry, „$” i „_”.
2️⃣ Wielkość liter ma znaczenie — Rekord i rekord to różne zmienne.
3️⃣ Nie wolno używać słów kluczowych JavaScript jako nazw zmiennych.

4) Typy zmiennych w JavaScript
JavaScript nie wymaga deklarowania typu – typ jest ustalany automatycznie po przypisaniu wartości.
Podstawowe typy zmiennych:
• Number – liczby całkowite i zmiennoprzecinkowe,
• String – tekst,
• Boolean – wartość logiczna (true/false),
• Null – brak wartości,
• Undefined – niezdefiniowana zmienna,
• Object – obiekt (np. tablica, funkcja itp.).
