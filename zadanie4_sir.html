Teoria JavaScript - Sirocki

1) Kiedy powstał JavaScript (podaj datę).
JavaScript powstał w 1995 roku (Brendan Eich opracował język w połowie 1995; w 1995 roku przedstawiono go w Netscape — powszechnie podaje się rok 1995).

2) Dlaczego jest to język skryptowy?
Ponieważ kod JavaScript jest zwykle interpretowany (wykonywany bezpośrednio przez środowisko — np. przeglądarkę) zamiast być uprzednio kompilowany do kodu maszynowego. Skrypty uruchamia się "na żywo".

3) Gdzie jest wykonywany JS (klient lub serwer)?
Najczęściej po stronie klienta (w przeglądarce użytkownika), ale też może być wykonywany po stronie serwera (np. Node.js).

4) Dlaczego JS to bezpieczne narzędzie?
JavaScript w przeglądarce działa w tzw. "sandboxie" — środowisku z ograniczonym dostępem do zasobów systemowych, co zmniejsza ryzyko bezpośredniego uszkodzenia systemu użytkownika. (Bezpieczeństwo zależy jednak od kodu i polityk przeglądarki.)

5) Czy jest to język obiektowy, jeśli tak to dlaczego.
Tak. JavaScript obsługuje obiekty, prototypy i (od ECMAScript 2015) klasy — umożliwia tworzenie i operowanie na obiektach, enkapsulację danych i metod.

6) Wymień zalety JS:
Zaleta1 – Łatwość nauki i szybkie efekty.
Zaleta2 – Działa we wszystkich nowoczesnych przeglądarkach.
Zaleta3 – Duża społeczność, biblioteki i frameworki (np. React, Vue, Angular).

7) Framework to:
Gotowy zestaw narzędzi i struktur (biblioteka + konwencje), który ułatwia budowanie aplikacji według określonego wzorca.

8) Do aplikacji mobilnych można użyć Framework
Tak — przykłady: React Native, Ionic, NativeScript — pozwalają tworzyć aplikacje mobilne wykorzystując JavaScript/HTML/CSS.

9) Aplikacje responsywne to:
Aplikacje/strony, które dostosowują układ i wygląd do różnych rozmiarów ekranów (telefony, tablety, PC) — używa się CSS (media queries) i elastycznych układów.

10) Przepisz linię kodu i wyjaśnij:
‹input type="button" name="przycisk" value="Nowa Strona" onclick="WinOpen(' ')"›
Wyjaśnienie: Tworzy przycisk formularza o nazwie "przycisk" i etykiecie "Nowa Strona". Po kliknięciu zostanie wywołana funkcja `WinOpen()` (która zwykle otwiera nowe okno). Użyte encje `‹` i `›` pozwalają wyświetlić znaki mniejsze/większe bez interpretacji jako HTML.

11) Przepisz linię i wytłumacz:
window.open("obraz.html","okienko","toolbar=no,directories=no,menubar=no,height=280,width=160,top=200,left=200");
Wyjaśnienie: Otwiera nowe okno lub kartę z zawartością `obraz.html`, nadaje temu oknu nazwę `okienko` i ustawia parametry: `toolbar=no` (ukrywa pasek narzędzi), `directories=no` (ukrywa przyciski katalogów), `menubar=no` (ukrywa pasek menu), `height=280` (wysokość okna), `width=160` (szerokość okna), `top=200` (odległość od górnej krawędzi ekranu), `left=200` (odległość od lewej krawędzi).

Opis opcji (krótko):
- toolbar=no → ukrywa pasek narzędzi przeglądarki w nowym oknie (jeśli przeglądarka pozwala).
- directories=no → historycznie ukrywa przyciski katalogów (rzadko używane współcześnie).
- menubar=no → ukrywa pasek menu (File/Edit itp.) w nowym oknie.
- height=280 → ustawia wysokość nowego okna na 280 pikseli.
- width=160 → ustawia szerokość nowego okna na 160 pikseli.
- top=200 → ustawia pozycję nowego okna 200 pikseli od góry ekranu.
- left=200 → ustawia pozycję nowego okna 200 pikseli od lewej krawędzi ekranu.

12) Opisz instrukcję window.close()
`window.close()` zamyka bieżące okno/kartę przeglądarki, w którym jest wywołana. Wiele przeglądarek pozwala na zamknięcie okna tylko jeśli zostało ono otwarte przez skrypt; zamykanie "ręcznie otwartej" strony może być zablokowane.

Gdy chcesz wyświetlić instrukcję, która nie powinna się wykonywać:
Pierwsza możliwość: znak `<` jako `‹`, znak `>` jako `›`.
Druga możliwość: umieszczenie tekstu w tagu `...` lub węwnątrz preformatowanego bloku `
...
` — wtedy przeglądarka pokaże kod, a nie wykona.
